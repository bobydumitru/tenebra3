Project log

Current repository state

  • Repository status: Rust implementation validated in release mode with full library and binary test coverage.
  • Current benchmark: 237 confirmed anonymous transactions in 1,400.82 ms, equivalent to 169.19 confirmed tx/s on the local Windows release build.
  • Required threshold: the measured result is within the requested 150–250 confirmed tx/s band.
  • Wallet status: the non-custodial browser wallet is publicly available and signs locally; the server never receives wallet seeds or passwords.
  • Launch boundary: this is an operational mainnet. The operational launch evidence does not claim perpetual uptime, market liquidity, or absolute anonymity.
  • Security posture: the custom proof path is tested, but independent cryptographic review and production operational review remain required before any real-value launch.
  • Project log / monetary log: 100,000,000 max TNB; 10,000,000 founder allocation; 90,000,000 mining allocation; 90% miner / 10% treasury fee split; price $1.00 USD/TNB and market cap $100,000,000 at max supply; this is a design value only and not a live public market price or trading claim.
