# Security Policy

## Supported versions

The project currently accepts security reports for the latest `main` branch.

## Reporting a vulnerability

Please report security issues privately to the maintainer or repository administrator.

Do not open a public issue for a vulnerability before it has been addressed.

## Automated checks

This repository includes automated security and quality checks via GitHub Actions:

- CodeQL
- Semgrep
- cargo clippy
- cargo test
- cargo audit
- Dependabot

## Response expectations

We will review and respond as quickly as possible, and we will coordinate a fix before public disclosure.
