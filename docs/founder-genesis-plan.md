# TSC-1 founder allocation configuration

The public receiving address approved for the founder allocation is stored in
`config/founder-address.txt`. The intended allocation is **10,000,000 TNB**,
which is 10% of the 100,000,000 TNB maximum supply. The remaining 90,000,000
TNB are reserved for mining.

This address is public data. Associating it with the founder allocation may
make related activity linkable. The address alone does not reveal a password or
private key, but it does not guarantee anonymity either.
