TENEBRA Wallet

Native signer

The browser wallet creates and encrypts a local wallet and shows its public address. The native Rust wallet performs full chain scanning, local signing, and transaction submission without sending the password or private key to a server.

Use

  1. Run the compiled tenebra-wallet application locally.
  2. Unlock the encrypted wallet file with its password locally.
  3. Enter recipient, amount in NOX, and fee.
  4. The application synchronizes mainnet, signs locally, submits the signed transaction, and shows the TXID.
