# TENEBRA treasury wallet

The dedicated public treasury address is stored in
`config/treasury-address.txt`. It is different from the founder genesis
address. The encrypted treasury wallet was created locally as
`%APPDATA%/TSC1/treasury.tsc1`; it is **not** stored in this project.

The owner must back up the encrypted wallet file and its password separately.
The public address is safe to publish, but publishing transaction flows can
reduce privacy. Never commit the password, seed, or encrypted wallet file to a
public repository.

The proposed 10% treasury fee share is not active. This address cannot receive
real TNB until a reviewed TSC-1 network and fee payout consensus exist.
